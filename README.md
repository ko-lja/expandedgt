GregTech Modern addon, searching to, as the name says, "Expand" upon the mod. The main goal of this is to add lots of GT/AE2 QoL, but also other stuff where i find that current GTM is lacking.

Currently added by the mod:

*   Expanded ME Input Bus | 36 Item Slots
*   Expanded ME Input Hatch | 36 Fluid Slots
*   Expanded ME Stocking Input Bus | 36 Item Slots
*   Expanded ME Stocking Input Hatch | 36 Fluid Slots
*   ME Tag Stocking Input Bus | Tag Based Item filtering Input
*   ME Tag Stocking Input Hatch | Tag Based Fluid filtering Input
*   ME Dual Output Hatch | ME Output and Bus in one, also output buffer increased from the normal 2³¹ to 2⁶³

_Note: There are currently no recipes included(will add some soon), it's up to you to add them._
